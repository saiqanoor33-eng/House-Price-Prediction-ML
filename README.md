# House Price Prediction using Machine Learning

## Project Overview

This project predicts house prices using a Random Forest Regression model built with Python and Scikit-learn.

## Features

* Generates a sample house-price dataset
* Prepares features and target values
* Splits data into training and testing sets
* Trains a Random Forest Regression model
* Evaluates predictions using MAE and R² score
* Predicts the estimated price of a new house

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn

## Input Features

* Area in square feet
* Number of bedrooms
* Number of bathrooms

## Dataset

The project generates 300 synthetic sample records for demonstration. The dataset does not represent actual property-market prices.

## How to Run

Install the required libraries:

`pip install pandas numpy scikit-learn`

Run the program:

`python house_price_prediction.py`

## Model Evaluation

The program displays the Mean Absolute Error (MAE), R² score, training/testing dataset sizes, and a sample price prediction.

## Conclusion

This project demonstrates the complete machine learning workflow, from dataset preparation and model training to evaluation and prediction.
